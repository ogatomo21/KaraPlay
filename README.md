# KaraPlay

## 概要

KaraPlayは、カラオケ練習用に曲のキーを楽に変更できるアプリです。

また、yt-dlpを用いたダウンロード機能も搭載しているため、YouTubeの音源を用いた練習も可能です。

もちろん、ローカル楽曲の再生も可能です。
